When using the AER consolidated report as a rate source, add the distributor's metering charge for Energex, Ergon Energy, Endeavour Energy and Essential Energy fixed charges, and the LFiT amount for Evoenergy, or the fixed/energy charges will not match the distributor's published NUoS price. The AER's own metering worksheet (2025-26 onward) holds the metering values.
2. Treat the AER file's zero-priced rows as "not published" rather than "free": the distributor's own list is the only source for new trial/flexible tariffs in the year they start (Energex, Ergon, SA Power Networks 2024-25, AusNet 2025-26).
3. For large-business and site-specific tariffs (Jemena A34x-A50x, AusNet NSP82/91/94/95, SA Power Networks HVADnnn/ZSSnnn/STRnnn) the consolidated report is incomplete; use the distributor's list.
4. Map codes with the alias rules in `scripts/reconcile.py` (joint codes, "-SA", T-region suffix, SAPN ZSN/ZSS and STN/STR prefix swaps, BCL vs M/QOPCL) before joining the two sources on tariff code.
5. The reconciliation is reproducible (`./run.sh`); when the AER publishes a new version (the 2025-26 and 2026-27 reports each went through five versions in the first four months of the year) re-run it against the versioned URL rather than the landing page. If this tooling is to be kept, commit `scripts/`, `sources/inventory.csv`, `notes/` and `run.sh`; the downloaded `sources/` files (91 MB) can be re-fetched from the recorded URLs except the Wayback copies, which should be committed.
